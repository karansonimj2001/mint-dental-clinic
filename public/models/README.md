# 3D model assets

Place optimized `.glb` files in this folder using these exact names:

- `stethoscope.glb`
- `tooth.glb`
- `dental-handpiece.glb`

The application includes graceful visual fallbacks when a model file is missing.
Only use models whose license explicitly permits your intended commercial use.
Keep attribution/license details in `ASSET_CREDITS.md`.
