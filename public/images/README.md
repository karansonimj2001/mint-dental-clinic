## Rules before using in the UI

- **Doctor portraits** → always presented as *fictional demo profiles*: use
  fictional names and a visible "Demo" label. Never write them as the clinic's
  real doctors.
- **Testimonial portraits** → always presented as *demo/sample reviews*:
  fictional names, a visible "Demo review" tag, no real medical claims.
- Never imply these images show actual staff, actual patients or the actual
  clinic premises.
- Replace every asset with verified, licensed, real content before any
  production launch for a real clinic.
- Icon tiles are non-transparent crops on white — use them on white or
  very-light backgrounds, or convert them to transparent PNG/SVG if they need
  to sit on colored panels.
